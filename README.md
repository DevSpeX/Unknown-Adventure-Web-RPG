# Unknown Adventure RPG

[![Platform](https://img.shields.io/badge/Platform-Web-blue)](https://unknown-adventure-rpg.web.app)
[![Tech](https://img.shields.io/badge/Stack-Vanilla%20JS%20%7C%20CSS%20%7C%20Firebase-orange)](https://unknown-adventure-rpg.web.app)

**Unknown Adventure RPG** is a feature-rich, browser-based RPG engine built with pure modern JavaScript (ES Modules), vanilla CSS, and Firebase. It features a complete server-side authoritative backend for persistence, an interactive world builder, and a robust turn-based combat system.

---

## 🎮 Live Demo
**Play now at:** [https://unknown-adventure-rpg.web.app](https://unknown-adventure-rpg.web.app)

---

## ✨ Key Features

- **Dynamic World & Locations**: Interactive network-based world navigation.
- **World Builder DevTool**: Visual canvas-based map editor for real-time world graph management.
- **Turn-Based Combat**: Strategic combat system with levels, skills, and loot.
- **Persistence**: Deep integration with Firebase Auth and Firestore for secure, cloud-saved characters.
- **Modular Architecture**: Clean separation of concerns with logic modules and UI components.
- **Dev Tools Suite**: Comprehensive in-game admin panel for content creation (Quests, NPCs, Dialogue, Items).

---

## 🛠️ Tech Stack

- **Markup**: HTML5 (Single Page Application)
- **Styling**: Vanilla CSS (Custom Medieval Dark Theme)
- **Logic**: JavaScript ES6 Modules (Zero build tools required)
- **Backend**: Firebase Authentication & Cloud Firestore
- **Deployment**: Firebase Hosting

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- Firebase CLI (`npm install -g firebase-tools`)

### Local Development
1. Clone the repository.
2. Run a local development server (e.g., `npx serve .`).
3. Open `http://localhost:3000` in your browser.

### Deployment
To host your own version on Firebase:
```bash
firebase init  # Select Hosting
firebase deploy
```
